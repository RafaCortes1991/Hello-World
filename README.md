Ejercicio Hello World.

Como se puede observar al entrar en la página, la idea del ejercicio era crear una página estática
con los colores e imágenes corporativos de Mozilla Firefox. Para tal fin, se nos proporcionó el material
necesario para conseguirlo: imágenes, colores corporativos en RGB y el texto a introducir.

Lenguas de programación utilizadas.

Como se puede observar en los documentos index.html y styles.css, los dos lenguajes principales 
utilizados para realizar el trabajo son HTML5 y CSS3. Si se preguntan de dónde sale el documento main.js, es una creación propia de GitHub, al tener por defecto activa la casilla .gitignore

Layout.

Como se puede observar al entrar en la página, aparece un título en que aparece la frase "Mozilla es genial, " y el nombre del usuario.
En el cuerpo se da una breve descripción e inglés de qué es Mozilla ( recuerdo que ese texto se nos proporcionó y tenía que aparecer sí o sí).
Y en el pie de la página un botón que da la oportunidad de cambiar de usuario. 

index.html

Como se puede observar, se ha utilizado una etiqueta importante, <h1>, una etiqueta de salto de línea, <p>, y un par de etiquetas para crear una lista desordenada, <ul> y <li>, una etiqueta <button> para crear el botón, y una etiqueta <link> para agruparlo todo con el documento CSS.

styles.css

En este documento utilizamos las etiquetas correspondientes para maquetear la página en todos sus ámbitos: el color, tamaño y justificación de fuente, color del fondo, ancho, alto y color del botón, etc. 

Funcionalidades.

1. Al clicar el botón, aparece una ventana que pide que pongas un nombre. al aceptar, el nombre aparecerá en el título <h1>.
2. Al clicar en las palabras "Mozilla Manifesto" nos conduce a la página oficial de Mozilla a su Manifesto en español.
